## 数据流时序

```mermaid
sequenceDiagram
    participant U as 用户
    participant G as Gradio UI
    participant S as 安全层
    participant C as 缓存层
    participant A as Agent 工作流
    participant R as 检索层
    participant L as LLM API

    U->>G: 输入问题
    G->>S: 限流检查
    S->>S: RBAC 鉴权
    S->>C: 查询缓存
    alt 缓存命中 (L1/L2)
        C-->>G: 返回缓存答案 + 标记类型
        G-->>U: 展示答案 (带缓存标识)
    else 缓存未命中
        C->>A: 进入工作流
        A->>A: classify_intent
        alt multi_hop
            A->>A: plan_sub_questions
        end
        A->>R: retrieve (FAISS + BM25 + RRF)
        R->>R: rerank (Cross-Encoder)
        R-->>A: top-5 精排文档
        A->>A: check_sufficiency
        alt 信息不足 & retry < 3
            A->>A: refine_query
            A->>R: 重新检索 (top_k×2)
        end
        A->>L: generate_answer (流式)
        L-->>A: token by token
        A->>S: PII 脱敏
        S->>S: 审计记录
        A->>C: 写入缓存
        A-->>G: 流式答案 + 来源
        G-->>U: 逐字展示 + 推理轨迹
    end
```
